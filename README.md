# チェーンボール（CHAIN BALL）

ビリヤードの新しいゲーム「チェーンボール」のスコア計算Webアプリ（単一HTMLファイル、ビルド不要）。

## ルール

- 球は1〜15番全部を使う。落とした球はテーブルに戻らない
- 複数人プレイ。プレイヤー名簿の並び順がターンの順番
- 最初のブレイクで入った球は順番を問わず「入った球の合計 ＋ 個数 × ブレイクボーナス」を加算（デフォルト1個 +5点、名簿画面で変更可能）。続投は、ブレイクで入った1桁の球のうち一番大きい番号が「前の球」になる（1桁がなければチェーンなし）
- ブレイクでファウルした場合、入った球の点数は無効でマイナス点＆ターン交代。空振りなどでラックが崩れていない場合は、次のプレイヤーがブレイクし直す（ブレイクボーナスあり）
- 1つ目の球はそのままの点数（例：2番 → +2点）
- 同じプレイヤーが連続で入れると「前の球 × 今の球」が点数（例：2の次に6 → +12点、その次に5 → +30点）
- ただし掛け算は1桁同士の時だけ。2桁の球（10〜15番）は掛け算されずそのままの点数（例：4の次に11 → +11点）。2桁を入れた後はチェーンもリセット
- 外したらターン交代（ペナルティなし）
- ファウル（手玉を落とす／どの球にも当たらない）はマイナス点＆ターン交代。点数はデフォルト −2点で、アプリ内で変更可能
- 手玉がポケットに入ったファウルは、そのターンに入れた球を台に戻して点数も取り消す。同じターンでブレイクしていた場合、ブレイクで入った球は戻さずブレイクの点数を取り消す。球に当たらなかった等のファウルは減点のみ
- 15個全部落ちたら終了。最高点が勝ち、最低点が負け

## 使い方

`index.html` をブラウザで開くだけ。スマホ対応（縦向き・横向きそれぞれ専用レイアウト。横向きでは左にボール、右に手番・順位・操作ボタン）。途中の状態はブラウザに自動保存されるので、閉じても続きから再開できます。

主なボタン：
- 球をタップ → ポケットとして記録し自動計算
- 「外した（交代）」→ 次のプレイヤーへ
- 「ファウル −2」→ 設定した点数を引いて次のプレイヤーへ
- ↩（左下）→ 直前の操作を取り消し
- 右上メニュー → ファウル点数の変更・ルール確認
- ゲーム画面の一番下 → ゲームをやめて名簿に戻る（2回タップで確定）

各ボールの下には「今入れたら何点か」が表示され、チェーン中の掛け算はゴールドで強調されます。
